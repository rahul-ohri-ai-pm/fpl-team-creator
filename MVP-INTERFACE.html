Mobile-first wireframes for the Phase 1 MVP. Each screen shows key user flows and interaction patterns. The design prioritizes decision-first UX: show the recommendation clearly, explain why, provide alternatives, allow "do nothing."

Next Steps

  1. Frontend stack: React (Vite) or HTML/CSS/JavaScript (lightweight)
  2. API integration: Wire recommendation engine (engine/score.py, engine/optimize.py) to web UI
  3. Screenshot import: Integrate OCR (TensorFlow.js or Tesseract.js)
  4. Shareable URLs: Generate short IDs, persist analysis results
  5. Responsive design: Test on 375px (mobile) and 1024px+ (desktop)
  6. Performance: Target <3s recommendation display on 4G
  7. Analytics: Track activation (recommendation viewed), engagement (share clicked), conversion (upgrade clicked)
